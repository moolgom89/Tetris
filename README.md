# Tetris Game

A modern implementation of the classic Tetris game using React and TypeScript.

## Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Installation

```bash
# Install dependencies
npm install

# Start the development server
npm start
```

## How to Play

- Use **Arrow Left** and **Arrow Right** to move the piece horizontally
- Use **Arrow Down** to move the piece down faster
- Use **Arrow Up** to rotate the piece
- Press **Space** to start a new game
- Clear lines to score points
- Game speed increases as you level up

## Features

- Modern React implementation with TypeScript
- Responsive design
- Score tracking and leveling system
- Smooth animations
- Game over detection and restart functionality

# 테트리스 게임

React와 TypeScript를 사용한 현대적인 테트리스 게임 구현입니다.

## 시작하기

### 필수 조건
- Node.js (v14 이상)
- npm 또는 yarn

### 설치

```bash
# 의존성 설치
npm install

# 개발 서버 시작
npm start
```

## 게임 방법

- **왼쪽 화살표**와 **오른쪽 화살표**로 조각을 좌우로 이동
- **아래쪽 화살표**로 조각을 더 빨리 떨어뜨리기
- **위쪽 화살표**로 조각 회전
- **스페이스바**로 새 게임 시작
- 라인을 없애서 점수 획득
- 레벨이 올라갈수록 게임 속도가 증가

## 특징

- React와 TypeScript를 사용한 현대적인 구현
- 반응형 디자인
- 점수 추적 및 레벨 시스템
- 부드러운 애니메이션
- 게임 오버 감지 및 재시작 기능
